🚀 Space Explorer

An interactive desktop application built with Python and Tkinter that allows users to explore the planets of our Solar System through a simple graphical interface.

✨ Features

- 🌍 Explore all 8 planets
- ◀️ Previous and ▶️ Next planet navigation
- 🔢 Planet counter
- 🔭 Detailed information about each planet
- 🔍 Search for planets
- ⭐ Starry space background
- 🖥 Interactive graphical user interface

🛠 Technologies

- Python
- Tkinter

▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run:

python main.py
