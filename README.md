# 🚀 Space Explorer

An interactive desktop application built with Python and Tkinter.

## ✨ Features

- 🌍 Explore all 8 planets
- ◀️ Previous and ▶️ Next navigation
- 🔢 Planet counter
- 🔭 Detailed planet information
- 🔍 Search for planets
- ⭐ Starry space background
- 🖥️ Interactive graphical user interface

## 🛠️ Technologies

- Python
- Tkinter

## ▶️ How to Run

Run the following command:

`bash
python main.py
